真实模型通过独立的 HTTP + WebSocket 端到端测试：

| 项目 | 实测 |
|---|---|
| 输入 | Qwen 官方 `asr_zh.wav`，4.203 秒 |
| ASR 原文 | 甚至出现交易几乎停滞的情况。 |
| 译文 | Even transaction almost stops. |
| 纪要 | • 甚至出现交易几乎停滞的情况。 |
| ASR 调用 | 20.197 秒 |
| 翻译调用 | 8.814 秒 |
| 纪要调用 | 0.651 秒 |
| 完整处理 | 30.669 秒 |

这是实际 Qwen 推理，调用包括冷模型加载与首次执行开销，不是实时延迟或热推理基准。首次独立 smoke 中 ASR 约 50.5 秒，说明首次初始化及运行条件会显著影响冷调用。单个样本不能作为准确率评价。译文能传递大意，但语法不佳，说明 0.6B 文本模型仅适合作为本地功能基线。

0.6B 文本模型曾在概括式纪要中加入原文没有的任务和结论，因此本地默认改为“模型选择关键句 + 程序从原文呈现”，并对不合法编号提供明确标注的原文摘录兜底。概括式纪要保留为配置选项，应在 AUP 上使用更强模型并人工核查。

真实测试的结构化结果在 `artifacts/real-qwen-e2e.json`（本机生成，不进 Git）；样本会议与录音保存在本机 `data/`，可在应用历史记录中回看。
